# Listing source icons

Official website favicon logos, downloaded 4 November 2026 and stored locally
under `apps/web/public/source-logos/` for reliable report rendering.

| Source | Original asset |
| --- | --- |
| Zillow | https://www.zillow.com/favicon.ico |
| Redfin | https://www.redfin.com/favicon.ico |
| LoopNet | https://www.loopnet.com/favicon.ico |
| Crexi | https://www.crexi.com/favicon.ico |

These marks identify links to their respective websites. The URL hostname
selects the logo, including for a separate listing-proof link. Link labels remain
visible and usable if an image cannot load. PDF exports include the source icons
before their names and clickable URLs. Local icons are rasterized for PDF format
compatibility; both the icon/name and URL cells remain clickable.
